# 参考资料：静水《可以分享一些你的交易策略吗？》要点

> 来源：静水2008 雪球文章（约 2026-10-12 发布），用户 10-14 以截图提供。据截图整理。

## 核心观点
1. **牌桌观念**：始终执行一个策略——**持股时间**。利润由持有时间与成长空间共同决定，选短选长都行，但要与策略一致。
2. 明确观念可以去除市场里大部分选股干扰；复盘做熟的公司。
3. 个人策略各有偏重：有人观察数据、有人看技术面、有人看经营路线——把各种视角整合进自己的体系。
4. **四种视角**：从产业成长选股；从产业发现公司；选择契合价值观的公司；比较财报与年报、季报（用数据验证）。

## 三个分析方向（本文核心）
| 方向 | 内容 |
|------|------|
| **定性分析** | 判断价值与背后逻辑：商业模式、护城河、读懂公司 |
| **定量分析** | 用财务数据支撑，用数据说话 |
| **比较分析** | 与对手比、与行业比、与世界比、与历史比 |

## 持有与复利
- 短线诱惑多；长线看产业与业绩。
- 看得远、拿得住是根基；长期坚持估值方法，不被短期情绪干扰。

## 对 Leo 的应用
- **三分析 = 读财报的笔记框架**：每份财报记三行——定性收获 / 定量验证 / 比较参照（同业、历史）。
- 与现有体系映射：定性 ≈ 逻辑穿透五问；定量 ≈ 三性与筛选门槛；**比较 ≈ 当前缺口**（看单一公司多、横向对比少）→ 每周复盘时补"同业对比"一栏。
