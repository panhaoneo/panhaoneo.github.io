# 跟踪方式解剖：中远海能航线全景（逐船跟踪）

> 来源：雪球 @憨憨派掌门人《中远海能-10月7日航线全景》，2026-10-07（PDF 存 `00_inbox/`，正文提取件同目录）。
> 用途：“选好股之后如何跟踪”的样板。整理 2026-10-12。

## 方式一句话
把公司还原成**可逐单元观测的物理对象**，用事件驱动持续跟踪每个单元的动向，再聚合出宏观结论，并与市场价格互证。

## 六要素解剖
| 要素 | 具体做法 |
|------|----------|
| 1. 基准名录 | 从财报建立跟踪全集：半年报船表 153 艘 + 新交付 1 艘 = 154 艘 |
| 2. 最小单元 | 每一艘船（IMO 编号唯一标识） |
| 3. 状态机 | 每艘船三态：当前航段 / 下一航向清楚 / 等待新信号 |
| 4. 事件捕捉 | 装货、卸货、转场、交付（AIS 船位 + 装卸事件，截至 10-07） |
| 5. 结构视角 | 先按船型分层（VLCC 48 / Suezmax 3 / Aframax 13 / LR2·LR1 20 / Panamax 22 / MR 48），再按航线走廊铺开（TD34 主轴 21 艘，占 45%） |
| 6. 互证与推导 | 船位动向 ↔ 运价互证（TD34 五周 +200%、TD20 +360% 等）；货盘分流模型：大船吃紧 → 拆向中型 → 逐级抬高，“螺旋向上” |

## 数据严谨性（值得学的细节）
- 作者因船名匹配错误主动更正（NAVE ELECTRON 新旧两船混淆）——用 **IMO 编号**核对身份。
- 船队口径更正：“41 自有 + 7 租入 − 1 转 FSO”，区分自有与租入。
- 图表由 AI 生成（评论区确认）——工具不神秘，关键是跟踪体系。

## 可迁移的通用原则
1. 找最小可观测单元（船 → IMO；船厂 → 船坞/订单；消费 → 门店/SKU）。
2. 从财报/公告建基准名录，维护为“全集 + 增量”。
3. 状态机管理：每个单元的当前状态、下一状态、等待信号——三态。
4. 事件驱动：装/卸/签约/交付，只记录变化。
5. 与价格互证：单元动向 ↔ 市场报价，避免主观叙事。
6. 微观推宏观：单元聚合 → 供求结论。

### 落地两步
- **第一步（现在就能做）**：逐笔订单跟踪表——从 imarine 与公告累积每笔签约（含选择权），标注船型/数量/交付期。
- **第二步（进阶）**：逐坞排产观察（新闻、卫星图中的船坞占用）。
